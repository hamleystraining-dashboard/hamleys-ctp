📥 How to Export Files from SharePoint

Follow these steps each time you want to refresh the dashboard with the latest data:

  1. Open SharePoint → navigate to CertifiedToPlay_Reports.xlsx (the joinees sheet) → Download
  2. Open SharePoint → navigate to Certified_To_Play.xlsx (MS Forms responses) → Download
  3. Open this Admin page → Upload Files tab
  4. Upload both downloaded files in the upload cards above
  5. Dashboard rebuilds automatically — all compliance numbers refresh instantly
💡 You only need to re-upload when data changes. The dashboard remembers your last upload and uses it each time the page loads.

📊 How Compliance Is Calculated

The dashboard reads raw responses from the MS Forms file and computes compliance per FC from scratch. It does NOT use any pre-calculated columns from the Excel file.

Step 1 — Determine Ideal Certifications (Denominator)

Days Since Day 0ZoneIdeal Certs Due
7 or more daysW1 — Demo1
15 or more daysW2 — CSD2
22 or more daysW3 — Product3
29 or more daysW4 — Selling4
36 or more daysW5 — VM5
43 or more daysW6 — Billing6 (Fully Certified)

Step 2 — Count Actual Certifications (Numerator)

For each FC, for each zone: scan all response rows matching that FC's Emp Code. If any row for that zone has Outcome = "Pass", the zone counts as certified (= 1). Multiple "Pass" entries for the same zone still count as 1. A zone with only "Reassessment" entries counts as 0.

Compliance % = Actual Certs ÷ Ideal Certs × 100
FC with 0 ideal certs → "Not yet due" (hasn't reached 7-day threshold)
FC with 6/6 actual certs → Fully Certified 🏆
Zones: Demo · CSD · Product · Selling · VM · Billing

📅 Day 0 Rules

  1. Day 0 = official start of the FC's journey. Always set to a Friday
  2. FCs may join any day of the week — Day 0 standardises their assessment schedule
  3. W1 Assessment = Day 0 + 7 days (next Friday if not already Friday)
  4. Each subsequent assessment = previous + 7 days
  5. FC joining Monday → Day 0 set to coming Friday → W1 assessment = Friday of week 2
  6. Day 0 is set in col L of the Joinees sheet, but can be overridden here without changing the Excel
