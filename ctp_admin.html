How Day 0 works: Day 0 is the official start of the FC's 6-week Certified to Play journey. All assessment windows are calculated from this date — Week 1 assessment = Day 0 + 8 days (extra day for Induction), then +7 days each week, all snapped to the nearest Friday. Set Day 0 to a Friday to keep assessments consistently on Fridays.

🔗 Power Automate → GitHub Live Data Setup

Set up fully automated live data flow — no uploads, no manual steps. Every MS Form submission updates the dashboard within ~30 seconds.

  1. Create a GitHub repo e.g. hamleys-ctp-data. Add file data/responses.json with placeholder [].
  2. Enable GitHub Pages: Settings → Pages → Deploy from main branch. Your dashboard URL: https://[org].github.io/hamleys-ctp-data/
  3. Place certified_to_play_dashboard.html as index.html and ctp_admin.html in repo root.
  4. Open flow.microsoft.com → New Automated Cloud Flow → Trigger: "When a new response is submitted" on your MS Form.
  5. Add step: Excel Online (Business) → List rows present in a table pointing to your SharePoint responses Excel.
  6. Add step: GitHub → Create or update file contents → path: data/responses.json → content: JSON-serialised rows from step 5.
  7. Generate a GitHub Personal Access Token (Settings → Developer Settings → Fine-grained PAT → repo write scope) and paste into the GitHub connector.
  8. In certified_to_play_dashboard.html set GITHUB_JSON_URL to your raw JSON URL.
  9. Submit a test form entry and verify the dashboard updates automatically.
