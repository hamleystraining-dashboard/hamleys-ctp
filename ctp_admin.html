📋 How to Export CSV from SharePoint

Follow these steps every time you want to refresh the dashboard with latest MS Forms responses:

  1. Open SharePoint → navigate to the Certified To Play.xlsx file
  2. Click Open in Desktop App (opens in Excel)
  3. In Excel: File → Save As → Browse
  4. Change file type to CSV UTF-8 (Comma delimited) (*.csv)
  5. Save to your Downloads folder
  6. Come back here → Upload Data tab → upload that CSV file
  7. Dashboard updates instantly for everyone on this device
