📥 Weekly Update Workflow

  1. Open SharePoint → download CertifiedToPlay_Reports.xlsx (joinees + Day 0)
  2. Open SharePoint → download Certified_To_Play.xlsx (MS Forms responses)
  3. Open this admin file locally in your browser
  4. Upload both files in Upload & Generate tab
  5. Adjust any Day 0 values in Set Day 0 tab if needed
  6. Click Generate New index.html → download the file
  7. Upload index.html to GitHub → done! Everyone sees updated data
💡 This admin file never needs to go on GitHub. Keep it on your laptop. Only index.html goes to GitHub each week.
