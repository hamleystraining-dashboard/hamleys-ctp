🔗 Power Automate → GitHub Live Data

Automate data flow so every MS Form submission updates the dashboard instantly — no uploads, no logins needed.

  1. Create GitHub repo hamleys-ctp-data. Add data/responses.json with [].
  2. Enable GitHub Pages → deploy from main branch. Place both HTML files in repo root.
  3. Power Automate: New Automated Flow → Trigger: MS Forms new response submitted.
  4. Add: Excel Online (Business) → List rows from SharePoint responses Excel.
  5. Add: GitHub → Create or update file → data/responses.json → JSON rows.
  6. Generate GitHub PAT (repo write scope) → paste into GitHub connector.
  7. Set GITHUB_JSON_URL in this file to your raw GitHub JSON URL.

📄 Manual CSV Upload

Click ⬆ Upload CSV in the top bar (or use the Admin Config page) to load a fresh export of the MS Forms responses.

For store data updates or Day 0 changes → open ⚙ Admin Config.
